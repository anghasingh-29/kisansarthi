# Kisan Yojana Saathi

Design a complete, modern, professional and responsive website UI for a project called KisanSarthi – Government Schemes & Eligibility Portal.

1. Project Overview

KisanSarthi is a farmer-support platform that helps farmers explore government schemes, understand sample eligibility requirements, prepare documents and track application progress.

I am responsible ONLY for the Government Schemes and Eligibility Section.

Create a beautiful, easy-to-use interface specially designed for Indian farmers. The website should look trustworthy, clean, accessible and professional.

2. Design Theme

Follow these design guidelines:

Primary colour: Forest Green (#1B5E20)

Secondary colour: Light Green (#E8F5E9)

Background: White (#FFFFFF) and very light grey (#F8FAF8)

Accent colour: Soft yellow or golden for highlights.

Use modern typography such as Inter or Poppins.

Use rounded cards, subtle shadows and clean spacing.

Use simple icons related to agriculture, documents, farming and government services.

Use a consistent header, navigation and footer throughout all six pages.

Avoid excessive animations and unnecessary decorative elements.

3. Create These Six Pages

PAGE 1 – Scheme Explorer

Design a page where farmers can explore available sample government schemes.

Include:

Page heading: "Explore Government Schemes"

Subtitle: "Find schemes that match your farming needs."

Search bar with search icon.

Category filter buttons:

All Schemes

Financial Support

Agriculture

Irrigation

Equipment

Insurance

Attractive scheme cards containing:

Scheme name

Short description

Category badge

Who can benefit

"View Details" button

Use fictional sample schemes and clearly label them as demo information.

PAGE 2 – Scheme Details

Design a detailed scheme information page.

Include:

Scheme title and category badge.

Overview section.

Who can benefit section.

Sample benefits section.

Required documents section.

Step-by-step application process.

"Check Eligibility" primary button.

Back to Schemes button.

Use organised information cards and clear section headings.

PAGE 3 – Eligibility Checker

Create a simple, user-friendly eligibility form.

Heading: "Check Your Eligibility"

Include these fields:

Select State (dropdown).

Farmer Category (dropdown: Small Farmer, Marginal Farmer, Other).

Approximate Landholding (dropdown).

Crop Type (dropdown).

Required Documents Available? (Yes / No / Not Sure).

Include:

Clear field labels.

Helpful instructions below fields.

Required field validation.

Submit button: "Check Eligibility".

Do not request Aadhaar numbers, bank account details, OTPs or passwords.

PAGE 4 – Eligibility Result

Design an attractive result page.

Include three possible result designs:

Potential Match (green status).

More Information Needed (yellow status).

Insufficient Information (grey status).

Each result should contain:

Status heading.

Relevant icon.

Short explanation.

Reasons for displaying the result.

Recommended next steps.

"Explore Other Schemes" button.

"Check Again" button.

Display this disclaimer clearly:
"This is a demonstration result based on sample information. It is not an official government eligibility decision."

PAGE 5 – Document Checklist

Create an interactive-looking document checklist page.

Include:

Heading: "Your Document Checklist"

Selected sample scheme name.

List of five sample documents.

Checkbox beside each document.

Completed document counter.

Progress bar showing completion percentage.

Example: "2 out of 5 documents completed".

Clear all / Reset checklist option.

Use a clean card-based layout.

PAGE 6 – Application Status

Design a page showing sample application progress.

Include four application cards with different statuses:

Draft

Prepared

Submitted (Demo)

Update Needed

Each card should display:

Fictional application ID.

Sample scheme name.

Application date (use clearly fictional demo dates).

Status badge.

Short status description.

Appropriate action button such as "Continue", "View Details" or "Review".

Clearly mention that all application records are fictional demonstration data.

4. Navigation Design

Create a consistent navigation bar with:

KisanSarthi logo and a simple leaf/farming icon.

Home (only as a navigation placeholder if needed).

Explore Schemes.

Eligibility Checker.

Document Checklist.

Application Status.

Keep the navigation simple and easy to understand.
